# tasklog

Log tasks from your terminal and export them as JSON or CSV.

## Install

    uv tool install .

## Usage

    tasklog add "write report"
    tasklog list
    tasklog export > tasks.json
    tasklog export --format csv > tasks.csv

All commands and options: [CLI reference](docs/reference/cli.md). Everything else: [documentation index](docs/README.md).
