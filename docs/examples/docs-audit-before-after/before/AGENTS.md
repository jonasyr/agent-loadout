# tasklog

> Agent entry point.

## Purpose

A small CLI that logs tasks in a local SQLite file and exports them.

## Commands

| Task | Command |
|---|---|
| Install | `uv sync --extra dev` |
| Test | `uv run pytest test/` |
| Lint | `make lint` |
| Run | `uv run tasklog --help` |
