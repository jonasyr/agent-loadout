# Tool use that just works Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents and their subagents use Serena, codebase-memory, Context7 and Microsoft Learn when they fit, through small never-blocking hints, and `loadout usage` measures whether it works.

**Architecture:** One stdlib hook script `plugins/loadout/hooks/tool_hint.py` handles PreToolUse (search and docs hints) and PostToolUse (reset on Serena or graph use) for both agents, with per-session state in loadout's state folder. A read-only module `cli/loadout/usage.py` counts tool families in local transcripts. The subagent card and `rules/tooling.md` become trigger-first.

**Tech Stack:** Python 3.11+ standard library, bash hook runner `run.sh`, pytest with `fake_home`/`fake_runner`.

**Spec:** `docs/superpowers/specs/2026-10-14-tool-use-design.md`

## Global Constraints

- Python 3.11+, standard library only in `cli/loadout/` and in hook scripts; hook scripts cannot import `loadout`.
- Hooks never block: output only `hookSpecificOutput.additionalContext`, never `permissionDecision`; always exit 0; silent on any error; 5 s timeout; `--soft` in the hook config.
- Hint text at most 300 characters, phrased as a fact. Subagent card under 400 characters.
- Search hint: fires on the 3rd symbol search since Serena or the graph was last used (`SEARCHES = 3`), at most one hint per 10 matched tool calls (`SPACING = 10`); never silent for the rest of a session.
- `loadout usage` prints counts only, never transcript content; default 14 days; `--json`; exit 1 only if no transcript folder exists for any agent that is on.
- Tests never touch the real `~/.claude`, `~/.codex`, `~/.config/loadout`, `~/.local/state`; hook tests run the script as a subprocess with a temporary HOME (like `tests/test_advisor.py`).
- Git: `/usr/bin/git` in plain single commands; Conventional Commits; no AI attribution.
- Tests: `uv run --python 3.12 --with pytest pytest -q`.

## Review Focus

- A search for a common word (`error`, `TODO`, `config`) or in a non-code repo gives no hint (Task 1 tests `test_common_words_never_count`, `test_non_code_repo_gives_no_hint`).
- Two hook processes of one session writing the state file at once: no crash, worst case one extra or missing hint (Task 1 test `test_concurrent_runs_never_crash`).
- A huge or binary payload: the hook stays fast and silent (Task 1 test `test_huge_payload_is_ignored_quickly`).
- `loadout usage` on malformed or huge transcript lines: skipped and counted, bounded memory (Task 4 test `test_malformed_and_oversized_lines_are_skipped_and_counted`).
- Codex payload shapes: `command` as a string or as a list of words (Task 1 test `test_codex_command_as_list_counts`).

"""tool_hint.py: a short, never-blocking hint after repeated symbol searches without Serena or the graph.
The hook runs as a subprocess with a temporary HOME and a fixture repo."""
import json
import os
import subprocess
import time
from pathlib import Path

import pytest

PLUGIN = Path(__file__).resolve().parents[1] / "plugins" / "loadout"
HOOK = PLUGIN / "hooks" / "tool_hint.py"
pytestmark = pytest.mark.skipif(os.name == "nt", reason="hook scripts run under python3 on POSIX")


@pytest.fixture
def home(tmp_path):
    h = tmp_path / "home"
    h.mkdir()
    return h


@pytest.fixture
def repo(tmp_path):
    r = tmp_path / "repo"
    (r / "src").mkdir(parents=True)
    (r / "pyproject.toml").write_text("[project]\nname='x'\n")
    (r / "src" / "app.py").write_text("def record_project():\n    pass\n")
    return r


def _run(home, payload, raw=None):
    env = {"HOME": str(home), "PATH": os.environ["PATH"]}
    stdin = raw if raw is not None else json.dumps(payload)
    res = subprocess.run(["python3", str(HOOK)], input=stdin, env=env, capture_output=True, text=True, timeout=10)
    assert res.returncode == 0
    return json.loads(res.stdout) if res.stdout.strip() else None


def _grep(repo, pattern, session="s1", path=None):
    tool_input = {"pattern": pattern, **({"path": path} if path else {})}
    return {"hook_event_name": "PreToolUse", "tool_name": "Grep", "tool_input": tool_input,
            "session_id": session, "cwd": str(repo)}


def _bash(repo, command, session="s1"):
    return {"hook_event_name": "PreToolUse", "tool_name": "Bash", "tool_input": {"command": command},
            "session_id": session, "cwd": str(repo)}


def _mcp(repo, name="mcp__plugin_loadout_serena__find_symbol", session="s1"):
    return {"hook_event_name": "PostToolUse", "tool_name": name, "tool_input": {}, "session_id": session,
            "cwd": str(repo)}


def _context(out):
    return out["hookSpecificOutput"]["additionalContext"] if out else None


def test_the_third_symbol_search_gets_one_short_fact(home, repo):
    assert _run(home, _grep(repo, "record_project")) is None
    assert _run(home, _grep(repo, "record_project")) is None
    out = _run(home, _grep(repo, "record_project"))
    text = _context(out)
    assert "record_project" in text and "search_graph" in text and "find_symbol" in text
    assert len(text) <= 300
    assert out["hookSpecificOutput"]["hookEventName"] == "PreToolUse"
    assert "permissionDecision" not in out["hookSpecificOutput"]


def test_shell_searches_count_also_behind_rtk_and_git_grep(home, repo):
    _run(home, _bash(repo, "rtk rg -n record_project src"))
    _run(home, _bash(repo, "cd src && grep -rn 'def record_project' ."))
    assert "record_project" in _context(_run(home, _bash(repo, "git grep record_project")))


def test_codex_command_as_list_counts(home, repo):
    for _ in range(2):
        _run(home, _bash(repo, ["rg", "-n", "record_project", "src"]))
    assert _context(_run(home, _bash(repo, ["rg", "record_project"])))


def test_serena_or_graph_use_resets_the_counter_and_drift_brings_the_hint_back(home, repo):
    _run(home, _grep(repo, "record_project"))
    _run(home, _grep(repo, "record_project"))
    _run(home, _mcp(repo, "mcp__plugin_loadout_codebase-memory-mcp__search_graph"))
    assert _run(home, _grep(repo, "record_project")) is None
    assert _run(home, _grep(repo, "record_project")) is None
    assert _context(_run(home, _grep(repo, "record_project")))  # drifted again: hint again, never silenced


def test_codex_mcp_names_reset_too(home, repo):

def test_spacing_allows_one_hint_per_ten_calls(home, repo):

    assert time.monotonic() - start < 5

def test_concurrent_runs_never_crash(home, repo):
    env = {"HOME": str(home), "PATH": os.environ["PATH"]}
    procs = [subprocess.Popen(["python3", str(HOOK)], stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                              stderr=subprocess.PIPE, env=env, text=True) for _ in range(8)]
    for p in procs:
        p.stdin.write(json.dumps(_grep(repo, "record_project")))
        p.stdin.close()
    for p in procs:
        assert p.wait(timeout=10) == 0 and p.stderr.read() == ""


def test_old_state_files_are_cleaned(home, repo):

    state.mkdir(parents=True)
    old = state / "old.json"
    old.write_text("{}")
    os.utime(old, (time.time() - 8 * 86400,) * 2)
    _run(home, _grep(repo, "record_project", session="new"))
    assert not old.exists() and (state / "new.json").exists()

#!/usr/bin/env python3
"""Tool hints (stdlib only, no network; always exit 0, silent on error; never blocks).

PreToolUse Grep|Glob|Bash (Claude Code) or Bash (Codex): on the SEARCHES-th symbol search since Serena or the code
graph was last used, add one short fact naming those tools. PostToolUse on a Serena or codebase-memory tool resets
the count. At most one hint per SPACING matched calls; never silenced for the rest of a session.
State: <state_dir>/tool-hint/<session_id>.json. See docs/reference/hooks.md."""
from __future__ import annotations

import json
import os
import re
import shlex
import sys
import tempfile
import time
from pathlib import Path

SEARCHES = 3
SPACING = 10
MAX_CHARS = 300
KEEP_DAYS = 7
MAX_INPUT = 200_000

IDENT = re.compile(r"[A-Za-z_][A-Za-z0-9_]{2,63}")
DECL = re.compile(r"\b(?:def|class|function|fn|func|interface|struct|type|enum|trait)\s+([A-Za-z_][A-Za-z0-9_]{1,63})")
CALL = re.compile(r"^([A-Za-z_][A-Za-z0-9_]{2,63})\\?\($")
COMMON = frozenset("""error errors todo fixme warning warn debug info test tests true false none null import from
return print main self this name path file data value values config http https version license readme string
true false def class function type""".split())
NON_CODE = (".log", ".md", ".markdown", ".rst", ".txt", ".json", ".jsonl", ".toml", ".yaml", ".yml", ".csv",
            ".lock", ".ini", ".cfg", ".env", ".html", ".xml")
CODE_MARKERS = ("pyproject.toml", "setup.py", "package.json", "Cargo.toml", "go.mod", "pom.xml", "build.gradle",
                "build.gradle.kts", "Gemfile", "composer.json", "mix.exs", "CMakeLists.txt", "Makefile")
CODE_EXT = (".py", ".ts", ".tsx", ".js", ".jsx", ".rs", ".go", ".kt", ".java", ".cs", ".rb", ".php", ".c", ".cc",
            ".cpp", ".h", ".hpp", ".swift", ".scala", ".ex", ".lua", ".sh")
SEARCH_CMDS = ("rg", "grep", "egrep")
TAKES_VALUE = frozenset({"-g", "-t", "-T", "-m", "-A", "-B", "-C", "-f", "--glob", "--type", "--type-not",
                         "--max-count", "--include", "--exclude", "--exclude-dir", "-d", "--max-depth"})
OPERATORS = frozenset({"|", "||", "&&", ";", ">", ">>", "<", "2>", "&"})
MCP = re.compile(r"^mcp__(?:plugin_loadout_)?(?:serena|codebase-memory-mcp|codebase_memory_mcp)__")
SHELL_TOOLS = frozenset({"Bash", "shell", "local_shell", "exec_command", "shell_command"})
SESSION = re.compile(r"^[A-Za-z0-9_-]{1,128}$")
FIND = ["<find of code files>"]  # shell_search's paths for a `find -name '*.py'`: a search without a symbol

SEARCH_HINT = ("`{name}` looks like a symbol. codebase-memory `search_graph` and `trace_path` give its definition "
               "and callers; Serena `find_symbol` and `find_referencing_symbols` give the exact place to edit.")
SEARCH_HINT_PLAIN = ("Searching code by text: codebase-memory `search_graph` and `trace_path` find definitions "
                     "and callers; Serena `find_symbol` finds the exact place to edit.")


def state_dir() -> Path:
    """The same rule as loadout's paths.state_dir() (this hook cannot import loadout)."""
    home = os.environ.get("HOME") or os.environ.get("USERPROFILE") or str(Path.home())
    base = os.environ.get("XDG_STATE_HOME", "")
    root = Path(base) if base and Path(base).is_absolute() else Path(home) / ".local" / "state"
    return root / "loadout" / "tool-hint"


def symbol(pattern: object) -> str | None:
    """The symbol a search pattern looks for, or None (a common word, a phrase, a regex soup)."""
    if not isinstance(pattern, str) or len(pattern) > 200:
        return None
    p = pattern.strip().strip("'\"")
    p = re.sub(r"^\^|\$$|\\b", "", p)
    m = DECL.search(p)
    if m:
        name = m.group(1)
    else:
        m = CALL.match(p)
        name = m.group(1) if m else (p if IDENT.fullmatch(p) else None)
    if not name or name.lower() in COMMON:
        return None
    return name


def _words(command: object) -> list[str]:
    if isinstance(command, list):
        return [w for w in command if isinstance(w, str)][:200]
    if not isinstance(command, str) or len(command) > 4000:
        return []
    try:
        return shlex.split(command)[:200]
    except ValueError:
        return command.split()[:200]


def shell_search(command: object) -> tuple[bool, str | None, list[str]]:
    """(is a search, symbol or None, path arguments) for the first rg/grep/git grep/find in a shell command."""
    words = _words(command)
    for i, w in enumerate(words):
        base = os.path.basename(w)
        if base == "find":
            rest = words[i + 1:]
            for j, x in enumerate(rest[:-1]):
                if x in ("-name", "-iname") and rest[j + 1].endswith(CODE_EXT):
                    return True, None, FIND
            return False, None, []
        if base == "git" and i + 1 < len(words) and words[i + 1] == "grep":
            return _search_args(words[i + 2:])
        if base in SEARCH_CMDS:
            return _search_args(words[i + 1:])
    return False, None, []


def _search_args(args: list[str]) -> tuple[bool, str | None, list[str]]:
    pattern, paths, skip = None, [], False
    for j, a in enumerate(args):
        if a in OPERATORS:
            break
        if skip:
            skip = False
            continue
        if a in ("-e", "--regexp") and j + 1 < len(args):
            pattern, skip = args[j + 1], True
            continue
        if a in TAKES_VALUE:
            skip = True
            continue
        if a.startswith("-"):
            continue
        if pattern is None:
            pattern = a
        else:
            paths.append(a)
    if pattern is None:
        return False, None, []
    return True, symbol(pattern), paths


def non_code(paths: list[str]) -> bool:
    return bool(paths) and all(p.lower().endswith(NON_CODE) for p in paths)


def code_repo(cwd: object) -> bool:
    if not isinstance(cwd, str) or not cwd:
        return False
    try:
        with os.scandir(cwd) as it:
            for n, entry in enumerate(it):
                if n > 300:
                    break
                if entry.name in CODE_MARKERS or entry.name.endswith(CODE_EXT):
                    return True
                if entry.name == "src" and entry.is_dir():
                    return True
    except OSError:
        return False
    return False


def _load(path: Path) -> dict:
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
        return data if isinstance(data, dict) else {}
    except (OSError, ValueError):
        return {}


def _save(path: Path, data: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=".tmp-")
    with os.fdopen(fd, "w", encoding="utf-8") as fh:
        json.dump(data, fh)
    os.replace(tmp, path)


def _clean(folder: Path) -> None:
    cutoff = time.time() - KEEP_DAYS * 86400
    try:
        for entry in os.scandir(folder):
            if entry.name.endswith(".json") and entry.stat().st_mtime < cutoff:
                os.unlink(entry.path)
    except OSError:
        pass


def _int(data: dict, key: str, default: int) -> int:
    v = data.get(key)
    return v if isinstance(v, int) and not isinstance(v, bool) else default


def _emit(event: str, text: str) -> None:
    out = {"hookSpecificOutput": {"hookEventName": event, "additionalContext": text[:MAX_CHARS]}}
    sys.stdout.write(json.dumps(out))


def search_event(tool: str, tool_input: dict) -> tuple[bool, str | None]:
    """(counts as a symbol search, symbol)."""
    if tool == "Grep":
        path = tool_input.get("path") or tool_input.get("glob") or ""
        if isinstance(path, str) and non_code([path]):
            return False, None
        name = symbol(tool_input.get("pattern"))
        return name is not None, name
    if tool == "Glob":
        pattern = tool_input.get("pattern")
        return isinstance(pattern, str) and pattern.endswith(CODE_EXT), None
    if tool in SHELL_TOOLS:
        is_search, name, paths = shell_search(tool_input.get("command"))
        if not is_search or non_code(paths):
            return False, None
        return (name is not None or paths is FIND), name  # a common word or a phrase never counts
    return False, None


def handle(payload: dict) -> None:
    session = payload.get("session_id")
    if not isinstance(session, str) or not SESSION.match(session):
        return
    event = payload.get("hook_event_name") or ""
    tool = payload.get("tool_name") or ""
    tool_input = payload.get("tool_input") if isinstance(payload.get("tool_input"), dict) else {}
    folder = state_dir()
    path = folder / f"{session}.json"
    fresh = not path.exists()
    state = _load(path)
    if event == "PostToolUse":
        if MCP.match(tool):
            state["searches"] = 0
            _save(path, state)
        return
    if event != "PreToolUse":
        return
    hit, name = search_event(tool, tool_input)
    if not hit and not extra_event(tool, tool_input, state):  # Task 2 adds docs hints here
        return
    if not code_repo(payload.get("cwd")) and hit:
        return
    calls = _int(state, "calls", 0) + 1
    state["calls"] = calls
    text = None
    if hit:
        searches = _int(state, "searches", 0) + 1
        state["searches"] = searches
        if searches >= SEARCHES and calls - _int(state, "last_hint", -SPACING) >= SPACING:
            text = SEARCH_HINT.format(name=name[:40]) if name else SEARCH_HINT_PLAIN
            state["searches"], state["last_hint"] = 0, calls
    _save(path, state)
    if fresh:
        _clean(folder)
    if text:
        _emit(event, text)


def extra_event(tool: str, tool_input: dict, state: dict) -> bool:
    return False


def main() -> int:
    try:
        raw = sys.stdin.read(MAX_INPUT + 1)
        if len(raw) > MAX_INPUT:
            return 0
        payload = json.loads(raw)
        if isinstance(payload, dict):
            handle(payload)
    except Exception:
        pass
    return 0


if __name__ == "__main__":
    sys.exit(main())

"""`loadout usage`: how often the agents used each tool family in local transcripts (counts only, read-only).
See docs/reference/cli.md#loadout-usage."""
from __future__ import annotations

import json
import re
import time
from pathlib import Path

from . import paths, targets

MAX_LINE = 1_000_000
FAMILIES = (("serena", re.compile(r"serena", re.I)),
            ("codebase-memory", re.compile(r"codebase[-_]memory", re.I)),
            ("context7", re.compile(r"context7", re.I)),
            ("microsoft-learn", re.compile(r"microsoft[-_](learn|docs|code)|microsoft_docs", re.I)))
BUILTIN = {"Grep": "grep", "Glob": "glob", "Read": "read", "Bash": "shell"}
CODEX_SHELL = {"exec_command", "shell", "shell_command", "local_shell", "exec"}
SEARCH = re.compile(r"(?:^|[\s|;&(])(?:rg|grep|egrep|git\s+grep)\s+(?:-\S+\s+)*(?:\"([^\"]+)\"|'([^']+)'|(\S+))")
IDENT = re.compile(r"^(?:(?:def|class|function|fn|func|struct|interface|type)\s+)?[A-Za-z_][A-Za-z0-9_]{2,63}\(?$")
NAMES = ("serena", "codebase-memory", "context7", "microsoft-learn", "grep", "glob", "read", "shell", "other")
LABELS = {"serena": "Serena", "codebase-memory": "codebase-memory", "context7": "Context7",
          "microsoft-learn": "Microsoft Learn", "grep": "Grep", "glob": "Glob", "read": "Read", "shell": "shell",
          "other": "other"}


def family(name: str) -> str:
    for fam, rx in FAMILIES:
        if rx.search(name):
            return fam
    return BUILTIN.get(name, "other")


def _group() -> dict:
    return {"sessions": 0, "calls": 0, "symbol_searches": 0,
            "families": {n: {"calls": 0, "sessions": 0} for n in NAMES}}


def _symbol_search(text: str) -> bool:
    m = SEARCH.search(text or "")
    pattern = next((g for g in m.groups() if g), "") if m else ""
    return bool(IDENT.match(pattern.strip()))


def _lines(path: Path, skipped: list[int]):
    try:
        with path.open("r", encoding="utf-8", errors="replace") as fh:
            for line in fh:
                if len(line) > MAX_LINE:
                    skipped[0] += 1
                    continue
                try:
                    obj = json.loads(line)
                except ValueError:
                    skipped[0] += 1
                    continue
                if isinstance(obj, dict):
                    yield obj
    except OSError:
        skipped[0] += 1


def _add(group: dict, calls: dict[str, int], searches: int) -> None:
    group["sessions"] += 1
    group["symbol_searches"] += searches
    for fam, n in calls.items():
        group["calls"] += n
        group["families"][fam]["calls"] += n
        group["families"][fam]["sessions"] += 1


def _claude(cutoff: float) -> dict | None:
    root = paths.claude_home() / "projects"
    if not root.is_dir():
        return None
    out, skipped = {"main": _group(), "subagent": _group()}, [0]
    for path in root.rglob("*.jsonl"):
        try:
            if path.stat().st_mtime < cutoff:
                continue
        except OSError:
            continue
        calls: dict[str, int] = {}
        searches = 0
        for obj in _lines(path, skipped):
            content = (obj.get("message") or {}).get("content") if obj.get("type") == "assistant" else None
            for item in content if isinstance(content, list) else []:
                if not isinstance(item, dict) or item.get("type") != "tool_use":
                    continue
                name, inp = str(item.get("name", "")), item.get("input") or {}
                fam = family(name)
                calls[fam] = calls.get(fam, 0) + 1
                if fam == "grep" and IDENT.match(str(inp.get("pattern", "")).strip()):
                    searches += 1
                elif fam == "shell" and _symbol_search(str(inp.get("command", ""))):
                    searches += 1
        _add(out["subagent" if "subagents" in path.parts else "main"], calls, searches)
    out["skipped_lines"] = skipped[0]
    return out


def _codex(cutoff: float) -> dict | None:
    root = paths.codex_home() / "sessions"
    if not root.is_dir():
        return None
    out, skipped = {"main": _group(), "subagent": _group()}, [0]
    for path in root.rglob("*.jsonl"):
        try:
            if path.stat().st_mtime < cutoff:
                continue
        except OSError:
            continue
        calls: dict[str, int] = {}
        searches, sub = 0, False
        for obj in _lines(path, skipped):
            p = obj.get("payload") if isinstance(obj.get("payload"), dict) else {}
            if obj.get("type") == "session_meta":
                sub = "subagent" in json.dumps(p.get("source", "")).lower()
            kind = p.get("type")
            if kind in ("function_call", "custom_tool_call"):
                name = str(p.get("name", ""))
                args = p.get("arguments") or p.get("input") or ""
                args = args if isinstance(args, str) else json.dumps(args)
                fam = "shell" if name in CODEX_SHELL else family(name)
                calls[fam] = calls.get(fam, 0) + 1
                if fam == "shell" and _symbol_search(args):
                    searches += 1
            elif kind == "mcp_tool_call_end":
                fam = family(str((p.get("invocation") or {}).get("server", "")))
                if fam != "other":
                    calls[fam] = calls.get(fam, 0) + 1
        _add(out["subagent" if sub else "main"], calls, searches)
    out["skipped_lines"] = skipped[0]
    return out


def _hint_sessions() -> int:
    folder = paths.state_dir() / "tool-hint"
    n = 0
    for path in folder.glob("*.json") if folder.is_dir() else []:
        try:
            data = json.loads(path.read_text(encoding="utf-8"))
        except (OSError, ValueError):
            continue
        if isinstance(data, dict) and isinstance(data.get("last_hint"), int) and data["last_hint"] > 0:
            n += 1
    return n


def collect(days: int, now: float | None = None) -> dict:
    cutoff = (now or time.time()) - days * 86400
    report: dict = {"days": days}
    if targets.claude_enabled() and (c := _claude(cutoff)) is not None:
        report["claude"] = c
    if targets.codex_enabled() and (c := _codex(cutoff)) is not None:
        report["codex"] = c
    report["hint_sessions"] = _hint_sessions()
    return report


def render(report: dict) -> str:
    lines = [f"Tool use in the last {report['days']} days (counts only):"]
    for agent, title in (("claude", "Claude Code"), ("codex", "Codex")):
        if agent not in report:
            continue
        for kind in ("main", "subagent"):
            g = report[agent][kind]
            if not g["sessions"]:
                continue
            fams = ", ".join(f"{LABELS[n]} {g['families'][n]['calls']} calls in {g['families'][n]['sessions']}"
                             for n in NAMES if g["families"][n]["calls"])
            lines.append(f"  {title} {kind}: {g['sessions']} sessions, {g['calls']} tool calls; {fams or 'no tools'}")
            lines.append(f"    symbol-like searches with grep/rg: {g['symbol_searches']}")
        if report[agent]["skipped_lines"]:
            lines.append(f"  {title}: {report[agent]['skipped_lines']} unreadable lines skipped")
    lines.append(f"  sessions with a loadout tool hint: {report['hint_sessions']}")
    return "\n".join(lines)

```markdown
# 0026: Tool hints add context, never block

Date: 2026-10-14. Status: accepted.

## Context

A count over the user's transcripts after setup showed Serena in 0.8% of Claude Code main sessions, codebase-memory in 1.2%, Context7 in 0.8%, Microsoft Learn never, and subagents almost never, while shell grep and rg ran thousands of times. Use happened about only when the user named the tool. Text in rules and cards alone did not change that. Blocking a search and redirecting costs about three calls for a one-call task and can loop.

## Decision

A hook adds one short fact next to a search or a docs web lookup that a better tool would answer: on the 3rd symbol search since Serena or the graph was last used, at most once per 10 matched calls, for the main session and (Claude Code) its subagents. It never blocks, never asks for permission, and is never switched off for the rest of a session, so an agent that drifts back gets it again. `loadout usage` measures the effect.

## Consequences

- A few hundred characters of context per hint; hints stay rare by design.
- The thresholds are constants in `plugins/loadout/hooks/tool_hint.py` and are tuned with `loadout usage`.
- Codex: the hint covers shell searches; whether PreToolUse runs in Codex subagents is not documented, so the measurement decides.
```

Add the line to `docs/adr/README.md` in the same style as the entry for 0025.
