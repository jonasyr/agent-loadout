# Testing gotchas
Use `fake_home` / `fake_runner` (tests/conftest.py); tests that need bash stubs or POSIX hook paths are skipped on Windows. Timing tests use roomy limits. The hook-merge property test reads seeds from `LOADOUT_PROPERTY_SEEDS` / `LOADOUT_PROPERTY_FIRST_SEED`.
Real installers run only in `.github/workflows/fresh-machine.yml` (fresh Ubuntu container, Windows experimental); entry-script tests (`tests/test_entry_scripts.py`) use stub binaries on PATH, never the network. They run bash in a new session (`start_new_session=True`) so results do not depend on whether the CI runner has a controlling terminal; the terminal test sets its own with `TIOCSCTTY`. Ubuntu's bash 5.2 differs from Arch's 5.3 (piped `BASH_SOURCE` is "main" vs empty): reproduce CI-only failures with `podman run ubuntu:24.04`.
Tests run in verbose output mode (autouse fixture); calm-mode tests set `out.VERBOSE = False`. Never run `git config --global` with HOME unset (`env -i`): git falls back to the real home and writes `~/.gitconfig` (it happened once; demo/sandbox.sh uses `--file`). VHS's `Wait` and `.txt` output read the top of the scrollback, so they stop matching once the screen scrolls: pace tapes with `Sleep`, check renders from mp4 frames (CONTRIBUTING.md#the-readme-demo).
Details: CONTRIBUTING.md#test-rules, docs/adr/0017-hooks-merge-per-hook-with-tombstones.md.
