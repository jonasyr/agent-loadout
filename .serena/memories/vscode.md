# VS Code
VS Code's extensions are a surface of an agent (ADR 0032, amended by 0034): detection is read-only in `cli/loadout/vscode.py`, check rows in `check._vscode_surfaces` (per extension and window), `check._vscode_path` and `check._vscode` (the WSL switch); Codex extension mode (no usable Codex CLI: `codex.mode()`/`program()`; plugins install with the extension's codex, the person approves hooks in the extension) in `codex.py` (ADR 0033, plugins and hooks superseded by 0038). Details: docs/how-to/vscode.md, docs/reference/setup-matrix.md.
Gotcha: `vscode.use_bundled_claude` puts the Claude Code extension's `claude` in `runner.FALLBACK`, so `runner.have("claude")` (PATH only) and what `runner.run` starts can differ: docs/reference/modules.md.
