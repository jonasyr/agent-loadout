# Architecture
Kit repo (plugin marketplace + `loadout` CLI) linked to a separate personal repo; settings merged three-way, rules linked as directories. Codex is a second target, with an extension mode for VS Code; repo files follow the repo's agents (`.loadout.json`). Map of modules: docs/reference/modules.md. Concepts: docs/explanation/architecture.md; state and sync: docs/reference/state-and-sync.md; decisions: docs/adr/README.md (Codex 0022/0024/0033/0038, repo files 0030/0031, update 0035, Serena remind 0039).
Gotcha: `cli/loadout/usage.py` counts searches with `cli/loadout/searches.py`; `plugins/loadout/hooks/tool_hint.py` is the docs hint only. Code searches are Serena's `remind` hook: docs/reference/hooks.md.
To change CLI behaviour touch `cli/loadout/<module>` and update the matching docs/reference page.
