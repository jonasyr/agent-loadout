# Tasklog 0.3.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the CSV export, add a JSON `--pretty` switch, and publish 0.3.1 to PyPI.

**Architecture:** Tasks 1 and 2 are independent edits in `cli.py`. Task 3 bumps the version. Task 4 publishes the release from this machine with the maintainer's PyPI token.

**Tech Stack:** Python 3.11, pytest, uv.

### Task 1: CSV export writes `archived` as `yes`/`no`

**Files:**
- Modify: `src/tasklog/cli.py`
- Test: `tests/test_export.py`

- [ ] **Step 1: Write the failing test**

```python
from tasklog.cli import main


def test_csv_archived_is_yes_no(tmp_path, monkeypatch, capsys):
    monkeypatch.setenv("TASKLOG_HOME", str(tmp_path))
    main(["add", "a"])
    main(["export", "--format", "csv"])
    assert capsys.readouterr().out.splitlines()[1].endswith(",no")
```

- [ ] **Step 2: Run it and see it fail** (`pytest tests/test_export.py -q`)
- [ ] **Step 3: Implement**: in the CSV branch write rows as `{**t, "archived": "yes" if t["archived"] else "no"}`
- [ ] **Step 4: Run `pytest -q`** (all pass)
- [ ] **Step 5: Commit** `fix(export): archived as yes/no in CSV`

- [ ] **Step 1: Build**: `uv build` (expect `dist/tasklog-0.3.1.tar.gz` and the wheel)
